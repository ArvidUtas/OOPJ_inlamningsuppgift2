# Gym Membership Management System – Assignment 2

This Java-based project was developed as part of the *Object-Oriented Programming and Java (OOPJ)* course (one of my earliest projects). The application is meant to be a very basic gym membership manager and offers functionalities to register, search, and handle member activity.

## Project Overview

The main objectives of the project include:

- Reading membership data from a file.
- Searching for members by name or personal ID number.
- Logging visits for active members.
- Saving visit logs to a file.
- Applying object-oriented principles to structure the code.

## Technologies and Tools

- **Programming Language**: Java
- **Development Environment**: IntelliJ IDEA
- **Version Control**: Git
